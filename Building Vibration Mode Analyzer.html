Building Vibration Mode Analyzer

This tool uses a simple mathematical model to show how eigenvalues and eigenvectors represent the natural vibration modes of a building.

Model: a 2-storey building. Each floor is a mass, connected by springs (stiffness). All values are user-defined / illustrative, not real building data.

1. Inputs

Mass = how heavy a floor is. Stiffness = how strongly the spring resists bending. Use positive numbers only.

2. Mathematical Calculation

We solve Kφ = λMφ. Multiplying both sides by the inverse of M gives Aφ = λφ, where A = M-1K.

M (mass matrix): floor masses on the diagonal. K (stiffness matrix): built from k1 and k2 as [[k1+k2, -k2], [-k2, k2]]. A: the matrix whose eigenvalues we need.

3. Results

  • Eigenvalue (λ): equals the square of the natural angular frequency (λ = ω²).
  • Eigenvector: the shape of a vibration mode. Each number is how far a floor moves sideways (floor 1, floor 2). Shown scaled so the largest value is 1.
  • ω = √λ (rad/s), and f = ω / (2π) (Hz).
